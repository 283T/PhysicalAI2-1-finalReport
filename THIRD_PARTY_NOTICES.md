# Universal Robots model

UR3e kinematics, inertias and mesh references in generated SDF are derived from UniversalRobots/Universal_Robots_ROS2_Description (ROS package ur_description 3.5.1).

Source: https://github.com/UniversalRobots/Universal_Robots_ROS2_Description/tree/jazzy

The UR3e data used here is BSD-3-Clause. Mesh files remain in the installed ROS package and are not copied into this repository. Other UR robot models with different mesh terms are not used.
