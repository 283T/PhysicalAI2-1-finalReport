# 基礎デモの検証記録

確認日：2026-10-10。Apple Silicon Mac上のDocker、ROS 2 Jazzy、Gazebo Sim 8.15.0を使用。

## 正常な挿入

`docker compose run --rm dev python3 scripts/run_insertion.py`で実行。

- 部品の持ち上げを確認。
- 解放・退避後の部品中心：(0.25, 0.15, 0.129999736) m。
- 目標：(0.25, 0.15, 0.13) m。
- ピン先端の挿入深さ：約40.0003 mm。
- 把持状態：detached。
- 成功判定：true。

## 穴を外す場合

生成したworldの基板をX方向へ15 mm移動し、作業指示は変更せず実行。供給トレイとロボットは元の位置のまま。

- ピックと基板上への搬送は成功。
- ピンが基板上面に接触し、挿入動作が目標へ到達せずタイムアウト。
- 部品中心のZ：約0.1700 m（正しい着座位置は0.1300 m）。
- スクリプト終了コード：1。
- 結果JSON：success=false。

穴の位置が誤っていても部品が基板を通過して成功扱いになることはなかった。この確認は、力制御や実機の挿入精度を保証するものではない。

再現する場合は、生成したSDFの`fixtures`モデル内で`pcb_`から始まるcollision/visualのposeのXへ0.015 mを加え、別のworldへ保存する。`--world`でそのworldを指定する。生成元と通常のworldは変更しない。

## 現時点で評価していない項目

- AIの図面読解精度。
- 図面の差し替えによる多品種対応。
- 実機の摩擦把持、細いピンの変形、精密挿入。
- 動画撮影（GUI表示とGUI上の挿入動作は[確認済み](gui.md)）。

最終課題の完成ではなく、図面読解を接続する前の動作基盤の確認。
