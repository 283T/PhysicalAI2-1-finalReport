# ハーネス接続デモの検証記録

確認日：2026-10-10。Apple Silicon Mac、ローカルOllama / Qwen3-VL 2B、DockerのROS 2 Jazzy＋Gazebo Harmonicを使用。

## AIによる接続図の読解

図面A・Bの2枚で、図面ID・部品分類・ハーネス番号・プラグ番号・接続先・X・Y・向きの8項目がすべて正解と一致。モデルには画像と共通プロンプト・出力形式だけを渡し、正解指示や配置一覧は渡していない。

| 図面 | ハーネス / プラグ | 接続先 | X / Y | 向き |
|---|---|---|---|---|
| A | WH1 / P1 | J1 | 60 / 50 mm | 0° |
| B | WH1 / P1 | J2 | 100 / 90 mm | 0° |

初回はBで部品分類に「WH1 / P1」、図面IDに見出し全体が返されたため、動作前に拒否した。[初回結果](evaluation/initial_harness_reading.json)を保存している。分類を`wire_harness`または`unknown`に制約し、図面IDは見出し内の識別子だけ返すよう共通プロンプトを修正した。座標や接続先を正解値へ補正する処理は追加していない。

修正後の[読解結果](evaluation/drawing_evaluation.json)は2/2件一致。ウォーム状態のモデルで約4.3秒・4.7秒だった。これは自作の簡略図面2枚の検証であり、一般の工場配線図に対する精度ではない。

## Gazeboでの接続

AIが生成したハーネス指示でA・Bともピック、搬送、差し込み、解放、退避に成功。

- Aのプラグ中心：約(0.25, 0.15, 0.15) m。
- Bのプラグ中心：約(0.29, 0.19, 0.15) m。
- 差し込み深さ：両方とも約40 mm。
- 解放状態：detached、success=true。

[Aの結果](evaluation/result_J1.json)、[Bの結果](evaluation/result_J2.json)にWH1/P1、機械的着座だけの判定であること、モデル名、画像SHA-256を記録する。赤・黒のケーブルと受け側ハウジングを表示したGUI上でも確認した。

## 指示の検証

`python3 -m unittest discover -s tests -v`：8件成功。A/Bの受理に加え、誤ったハーネス番号、プラグ番号、部品分類、接続先、座標、非数値・非有限値、単位、向き、校正値を拒否する。

## 再現範囲と限界

ケーブルは固定形状の視覚モデルで、プラグと一緒に動く。ケーブルの変形、張力、絡み、接触、他端固定の条件は評価していない。成功判定はプラグの機械的な着座で、ラッチ係合・接点圧力・電気的導通は判定しない。

以前の電子部品挿入デモの結果は[過去の記録](archive/pcb/validation.md)に保存した。現在のハーネス版とは分けて扱う。
