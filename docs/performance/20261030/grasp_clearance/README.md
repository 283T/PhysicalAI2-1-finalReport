# パレットとの余裕を保つ把持位置の診断

右第2関節I=200候補は初回閉指前画像で位置0.407965 mm／角度0.004221 radを通過した。閉指の開口検査も通過したが、primary_liftの事前検査がfraction=0で右指とパレットの余裕不足を拒否した。
成功ではなく全体失敗。独立監査も失敗。保持・100 mm上昇には未到達。

screen_offsets.pyは保存した失敗時の実測関節と閉指エンベロープを使うオフライン計算。
0 mmの元姿勢は同じ組合せで拒否され、工具の接近軸と反対方向へ1／2／3／4 mmずらす仮定のIK・100 mm持ち上げは、各81標本の腕／治具検査を通過した。
腕の余裕5 mm／治具の余裕1 mmは維持する。
この結果は開始からの全経路・実際の指と物体の接触・把持保持の証明ではない。保存関節や物体状態をシミュレータへ復元しない。

任意フラグ--primary-grasp-clearance-m（既定0、有限0〜0.004 m）を追加し、概要画像の把持関係を作る前に工具の負Z軸へ指定距離ずらす。高精度画像での再計画にも同じ物体対工具の関係を渡す。
次は0.002 mで新規開発試行を行う。全画像照合・補正予算・精密終了・把持・接触・保持・時間予算を維持する。指・パレットの形状や衝突判定を削除しない。

全284テスト通過。任意姿勢での外向き変換と入力の不変、既定0の維持、異常値拒否、高精度画像への把持関係の保持を確認。CLI異常値8件も出力／シミュレータ作成前に拒否した。
