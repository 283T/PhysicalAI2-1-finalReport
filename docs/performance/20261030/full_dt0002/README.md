全工程5分以内は未達で、成功時の速さとは扱わない。

終了後のnative照合では、最初の概要カメラ誤差は位置約1.380 mm／角度0.02849 rad、閉指前の検査カメラでは約0.169 mm／0.004717 rad。

次は腕を動かす前に既存の検査用高精度カメラを使えるか、小さな新規画像診断で確認する。真値は終了後の照合専用とする。
