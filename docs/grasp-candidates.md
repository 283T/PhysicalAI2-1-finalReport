# 試作端末の6D姿勢と把持候補

RGB-D画像から端末の中心と立体姿勢を推定し、把持候補・接続先上方の工具姿勢を計算する。左右のグリッパーも開閉できるようにした。ここまでの検証は画像認識、幾何学的な候補、空の指の開閉、物体のない隔離シーンでのアーム到達であり、端末の保持・持ち上げ・支持・挿入は未検証。

## 一括実行

```bash
python3 scripts/run_perception_demo.py \
  --design-seed 101 --placement-seed 2 \
  --output outputs/grasp_pipeline --require-6d --evaluate --check-reach
```

`--check-reach`はローカルQwen3-VLで今回の図面を読み、基板と照合してIKを計算し、各腕を別々のシーンで検証する。6D情報がある場合は把持候補への到達も検証する。`--require-6d`は3端末すべての中心・立体姿勢が安定するまで観測を受理しない。6D情報のない旧画像の平面検出を把持候補として扱わない。

## 認識の仕組み

既知形状40×20×20 mmの試作ハウジングを使う。端末IDは赤・青・黄で識別し、長軸の正方向に白マーカー、負方向に面識別マーカーを置く。

| 面の外向き法線（端末座標系） | 面識別色 |
| --- | --- |
| +Z | マゼンタ |
| −Z | シアン |
| +Y | 緑 |
| −Y | 黒 |

深度を実際のCameraInfoの内部パラメータで逆投影し、RANSACとSVDで主な可視面の平面を求める。同じ平面にある白・面識別マーカーから長軸と面法線を復元し、既知の半幅10 mmを差し引いて端末中心を得る。二面が見える場合に画像上の色画素数だけで面を選ぶと曖昧になるため、平面に一致する画素だけで面コードを判定する。面や平面が曖昧なら6D結果を出さない。

認識器へGazebo正解姿勢や配置JSONを渡さない。正解姿勢の購読は評価プロセスに限定する。カメラ外部パラメータは既知のシミュレータ設定であり、実測校正ではない。端末認識は色・幾何処理で、課題のAI活用はローカルモデルによる図面読解が担う。

## 把持候補と開閉

工具Z軸を可視面へ向け、指は長軸に垂直な短辺方向から閉じる。工具先端を端末中心から面法線方向へ2 mm置く幾何学的候補と、その100 mm手前の待機姿勢を作る。接続先では端末を図面のyawへ向け、端末と工具の相対変換を保って基板原点から160 mm上方の工具姿勢を求める。実際の挿入姿勢や衝突しない経路を求めた結果ではない。

各グリッパーの2本の指は独立した対向直動関節。開指令の隙間は52 mm、空の閉指令は16 mmである。20 mm幅の端末をつかむ場合、接触で指が止まる必要があり、空の閉指令への到達を保持判定に使わない。

```bash
# 一括デモが生成した、両腕だけの空のMELFAシーンで検証
docker compose run --rm dev python3 scripts/check_grippers.py \
  --world outputs/melfa_worlds/arms_test.sdf --output outputs/gripper_check
```

## 検証記録（2026-10-11）

| 図面／配置 | 検出数 | 最大中心誤差 | 最大立体姿勢誤差 |
| --- | --- | --- | --- |
| D100／seed1 | 3/3 | 1.25 mm | 1.29° |
| D101／seed2 | 3/3 | 1.53 mm | 0.80° |

姿勢誤差は回転行列間のSO(3)角度。認識受理は位置変化3 mm・回転変化0.08 rad以内が3フレーム続く条件、評価は中心誤差5 mm・姿勢誤差0.12 rad以内を条件とする。これは二つの試作配置の結果で、任意形状・任意配置の成功率を示さない。この二つの物理試行で観測された主面は−Yであり、4面の判別は合成RGB-D画像のテストで別途確認した。

- [seed1の認識記録](evaluation/pose6d_seed1/validation.json)、[seed2の認識記録](evaluation/pose6d_seed2/validation.json)：RGB、圧縮深度、内部・外部パラメータ、検出、評価用正解を同じフォルダへ保存。`depth.npz`の`depth`配列がm単位の深度画像。保存画像からの再検出が記録した中心座標と一致することも確認。
- [seed2の把持候補とIK](evaluation/pose6d_seed2/grasp_plan.json)：P1・P3に左腕、P2に右腕の候補。図面読解結果は既存のD101ローカル推論記録を再利用し、今回の基板との整合性を再検証した。
- [9目標の到達記録](evaluation/pose6d_seed2/motion_validation.json)：把持候補を含めて全目標に到達。最大工具位置誤差5.71 mm。位置6 mm・姿勢0.04 rad・関節誤差0.02 rad以内が5回続く条件で判定。各腕を隔離し、物体を除いた検証。
- [空のグリッパー開閉](evaluation/pose6d_seed2/gripper_validation.json)：両腕で開→閉→再開を確認。最大指位置誤差0.50 mm以内。
- 38件の単体テストを通過。4面の姿勢復元、面コード欠落の拒否、回転の安定判定、相対把持変換、指の関節構造を含む。

次は実際の端末を指で保持して持ち上げる試験を行う。摩擦・接触、ケーブルの張力、支持する腕、接続済み端末の拘束を検証してから挿入工程へつなぐ。
