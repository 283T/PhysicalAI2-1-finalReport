# 下降中の指の非対称変化と把持位置の診断

進行中の試験58060、物理172.0073秒・治具搬送4の途中を読み取った。指令経路の割合は59.87%。試験は終了しておらず、着座・接続の成功を示さない。制御・物理・把持参照は変更していない。

右指の閉指時と観測時の実測値：

| 項目 | 閉指時 | 観測時 |
|---|---:|---:|
| 左側の指の移動 | 2.096 mm | 約0 mm |
| 右側の指の移動 | 1.926 mm | 4.000 mm |

両指の移動差の半分は閉指時から−2.085 mm変化し、コネクタの工具X方向の位置関係は+2.067 mm変化した。符号を反転した差は約0.018 mm。この対応は把持中心の変化を示唆するが、単一の途中観測で因果を断定せず、力の測定とも扱わない。

右の相対移動の大きさ2.069 mm・角度変化0.01288 radは保持基準内。これが最終的な着座の位置・高さへ影響するかは、終了結果から別に判定する。左ワイヤー支持の相対移動は0.346 mm・角度変化0.01713 rad。

`inspect_grip_progress.py` に実測指位置、閉指時の指位置、工具座標での相対移動ベクトルを追加した。このベクトルのノルムが保存した把持位置変化と一致することを両側の実データで検算した。これは診断出力だけの変更で、実行中の制御は読み込まない。
