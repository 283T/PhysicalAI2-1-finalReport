# 37583：未把持P2と右指の接触による外部停止（失敗）

同じ設計101・配置2・world・モデルで、実行開始時から把持中心保持 `--centred-grips` を指定した比較。実行コード989ffdbと全scriptsのSHAは `control_sources_checkpoint.json`、プロセス識別は `world_session_checkpoint.json` に保存した。稼働中のシーン・物理・指・制御を変更していない。

右単独／双腕それぞれの100 mm上昇・4秒保持、新規RGB-D照合、腕の搬送経路0〜3は収束したが、水平搬送2からP1／P2と共用治具の接触が発生していた。搬送工程の合格とは扱わず、最終下降4も完了していない。P2のピンと右指が物理164.7821秒から、本体と右指が165.1358秒から接触。`descent_all_contacts_probe2.json` ではP2と治具の同時接触、P1と治具の接触も保存した。追従不足の唯一の原因とまでは断定しないが、未予定接触自体を不合格とする。

証拠を保存してから、識別した制御PID152へSIGINTを送った。最終下降の指令割合55.84%、物理20.900秒／実時間830.86秒で外部停止。予算60秒の終了ではない。`external_stop.json` が停止理由。終了報告はsuccess=false、trial_state=finished。SIGINTがROSを先に終了したため最終開指publishも失敗し、元の `teardown_error` を保持している。終了状態を正常開放や着座と扱わない。

隣の `centred_unplanned_connector_contact_grips.json` は右183,673／左151,456の把持標本を全件再計算して記録と一致した。最大ずれ0.990／0.187 mm、回転0.03212／0.01146 rad。把持基準内でも、接触監査は不合格。`centred_unplanned_connector_contact_contacts.json` は腕との接触と共用治具への未把持部品の接触を含めた監査。P1の治具接触は物理142.9585秒から、P2は143.5945秒から。いずれも不合格で、挿入未到達も残す。

`post_failure_camera` は終了後に同じシーンから取得した実画像3枚で、腕に遮られる部分もある。接触の特定は画像だけで判断せず、ネイティブ接触ログと照合する。画像取得後に診断用worldをpauseし、その応答も保存した。停止・pause後の状態を成功証拠や再開時の保存姿勢へ流用しない。

約定した全体完成・最終12試行の対象ではない。次は未把持部品への接触を即時停止する監視と、搬送時のケーブル出口・未接続端子の位置関係を修正して、新しい初期試験で検証する。元の全ログ、モデル、world、画像、失敗結果は保存したままにする。
