# 協調した治具配置の開発試験（2026-10-16）

固定D101／配置2／P3。最終受入12試行とは別。新規RGB-Dと実測関節から計画し、コネクタの物体真値は目標生成に使わない。治具の既知の幾何を使う。右の保持を再観測し、開放・退避後の安定までを同じROSセッションで実行する入口を追加した。基板挿入・上面持ち替えはまだ対象に含まない。

## support_branch_rejected（失敗）

右保持は通過したが、左の経路開始状態が拒否された。実測左肘が0 radの下限に対して−2.759859875356401e-14 rad。腕・固定設備の箱の重なりはなかった。治具への搬送へは未到達。失敗を保持し、修正後の成功に置換しない。

`support_branch_replay.json` は同じ保存観測・実測関節からの再計算で、物理試験ではない。開始値の限界から1e-12 rad以内の数値丸めだけを正規化する修正で、左ホバー・接近の経路が通過した。3候補の開始値補正は肘の+2.759859875356401e-14 radのみ。全計画点は限界内で検査する。1e-6 radの実際の限界超過を拒否するテストも通過。入力ファイルの対応は `support_branch_replay_inputs.json`。

閉指・保持・衝突の判定を緩めた変更ではない。実行中の再試験は `docs/goal-status.md` に記録し、終了結果を確認してからここへ保存する。

## rotation_finger_interval_rejected（失敗）

双腕保持を通過し、保持中の新しい画像は工具関係の誤差0.536 mm／0.00650 radで照合を通過。新しい関節・画像から再計画した4候補目で搬送0を完了し、回転工程1へ進んだ。右の指が約0.507 mm再中心化し、箱の仮定である実測値±0.5 mmの下限を約6.95 µm外れて停止。腕・設備の意図しない接触0件。治具着座・開放・退避は未到達。

`rotation_grip_replay.json` は右15729・左5496観測を最初の閉指参照から再計算した結果。右の最大ずれ0.604 mm／0.01040 rad、左0.0168 mm／0.0000362 radで、把持自体は基準内だったが、試験全体は失敗のまま。

`full_stroke_request.json` はこの試験の新規計画要求を保存し、指の全機械ストロークを検査する指定を加えたオフライン入力。`full_stroke_preflight.json` では両腕の左右の指を各[-0.5,20.5] mmで包含し、全5工程が腕同士5 mm・設備1 mmの余裕を含め通過した。入力の対応は `full_stroke_replay_inputs.json`。実行でも同じ包絡と指位置監視を用いる。物理試験の成功ではなく、次の物理比較の事前検査。開口・保持・衝突の成功閾値を緩める変更ではない。

## full_stroke_support_rotation_rejected（失敗）

全ストロークを含む包絡で搬送を実行し、指の再中心化による停止点を越えた。回転工程1で左のワイヤーの相対角度変化0.051726 radが上限0.05 radを超え、停止。位置変化0.625 mm。右の最大ずれ1.216 mm／0.01931 radは基準内。意図しない腕同士／設備接触0件。`support_rotation_grip_replay.json` は右14252・左6154観測を再計算し、同じ失敗を132.441秒で検出した。試験を成功へ置き換えない。

## 両工具の相対姿勢を保つ経路の事前検査

`rigid_request.json` は直前の試験の新規画像・実測関節に由来する計画要求。両工具の相対位置・姿勢を保つ指定を加えた。材料の剛体化や物体の固定・アタッチではない。`rigid_initial_diagnostics.json`（通常間隔）、`rigid_refined_diagnostics.json`（1/2間隔）、`rigid_dense_diagnostics.json`（1/8間隔）は、開始位置または治具位置で直接回転する各8候補の失敗を保存した。関節限界、連続性、IK誤差を緩和していない。

`rigid_midpoint_plan.json` は、途中50%の位置で回転する6工程の3候補目が通過した結果。連続IKは位置2.5 mm／角度0.0125 rad間隔。全工程の工具間距離140.667 mm以上、相対位置差0.363 mm以下／姿勢差0.012505 rad以下。指の全ストロークを含む腕同士・固定設備の包絡検査も通過。入力の対応は `rigid_replay_inputs.json`。物理試験の成功ではなく、次の再試験で新規観測から計画し直す方針。

`nest_camera_geometry.json` は次工程用の追加視点の静的検査。光学校正とworldの幾何の整合、追加カメラ以外の既存world・図面・基板・配置JSONの不変を確認した。画像認識の成功証拠ではない。この比較で実行したworldには追加カメラを入れていない。

## rigid_midpoint_support_rotation_rejected（失敗）

中間位置への並進後、両腕回転の工程2で左ワイヤーの相対回転0.056412 rad／移動2.024 mmにより停止した。右の最大変化1.324 mm／0.039145 radは基準内。腕同士・設備接触0件。`rigid_midpoint_grip_replay.json` は右18641／左10205観測を再計算し、152.6秒の失敗を再検出。治具への着座・開放・退避は未達成。

`rigid_grip_tracking_analysis.json` はロボットの工具追従を分けた診断。停止時の指令と実際の工具間関係の差は15.00 mm／0.09826 rad。各工具の指令追従誤差は右2.15 mm／0.07439 rad、左5.62 mm／0.06388 rad。計画上の相対枠の保存だけで実行時の同期を保証できていなかった。回転ベクトルの長手方向／垂直方向への投影も保存したが、トルクや原因の確定とは扱わない。再実行は `scripts/analyze_grip_tracking.py --pickup <archive>/pickup --output outputs/tracking.json`。

この結果から次の比較は `--feedback-paced-transfer` を追加する。各工具1 mm／0.01 rad・関節0.01 rad・相対工具枠1.5 mm／0.015 radまで追従してから小さい指令更新を許す。指令の上限は0.5 mm／0.003 rad／関節0.01 rad。最初の閉指参照と保持の5 mm／0.05 rad、接触・包絡、着座の条件は変更しない。停止による所要時間の増加を含めた有限の実行予算と、進行／待機の統計を各preflightに保存する。過去の失敗を再判定しない。

`predicted_top_regrasp.json` は保存した予定の治具姿勢から、開指後の80 mm退避と上面ホバーを検査した予備結果。退避は通過したが、上面ホバーは右前腕と左上腕の干渉で拒否された。実際の着座や開放後画像ではなく、指位置も仮定しているため実行目標に使わない。前提と参照計画のハッシュは `predicted_top_regrasp_inputs.json`。

## feedback_pacing_stalled（失敗）

工具・関節の追従を待つ制御で中間への並進を完了。回転工程2は指令経路の1.047%で進行ゲートを満たせず、規定の95.472シミュレーション秒で終了した。右65033／左55179観測を再計算し、把持は全て基準内（右最大2.010 mm／0.00973 rad、左0.454 mm／0.00854 rad）だったが、回転・配置が未達成なので全体は失敗。`feedback_pacing_grip_replay.json` に保存。各工程の進行・待機数、ゲート、更新上限、時間予算、最大追従差、到達した経路割合は `pickup/validation.json` のpreflightsに残る。

同じ指令がGazeboへ届いていることを別のネイティブ購読で確認した。公式 [JointPositionControllerの実装](https://github.com/gazebosim/gz-sim/blob/gz-sim8/src/systems/joint_position_controller/JointPositionController.cc) も調査したが、今回の内部積分値・実トルクを測ったものではない。制御ゲートを広げる代わりに、次は左joint6だけP/Dを変更して比較する。`wrist640_controller_tuning.json` と `wrist640_model_validation.json` は、P320→640、D0.2→0.2828427以外のworld要素と図面・基板・初期配置が変わっていないことを確認した記録。物理結果は次の試験で確定する。

`top_regrasp_parked_left.json` は `regrasp_plan.plan_top_pickup` の予備検査。左を直立・開指、右の退避と治具着座が完了した予定状態を仮定すると、右のホバー・接近・上昇が箱検査を通過した。参照計画のハッシュと仮定を含める。実際の着座、新しい画像、開放・退避・閉指を示す結果ではなく、実行用の目標へ転用しない。
