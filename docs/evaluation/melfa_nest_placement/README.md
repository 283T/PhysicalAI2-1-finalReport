# MELFA治具配置の試験記録（2026-10-13）

物理試験はすべてD101／配置seed2、左P1・右P3、分割接触パッド、ローカルQwen3-VL読解と新しいRGB-D観測を使用しています。治具配置まで成功した試験はありません。

| 保存先 | 指形状・ゲイン | 停止工程 |
|---|---|---|
| `gain1000` | 分割パッド・1000 | 持ち上げ後の回転保持を拒否 |
| `gain3000` | 分割パッド・3000 | 持ち上げ後の回転保持を拒否 |
| `backstop` | 背面ストッパー・3000 | 持ち上げ後の回転保持を拒否 |
| `capture` | 前後ストッパー・3000 | 把持前の下降が未到達 |
| `capture_diagnostic` | 前後ストッパー・3000・接触診断追加 | 前面ストッパーがピン・トレイへ接触、下降が未到達 |
| `single_front` | 正の工具X側だけの前面ストッパー・3000 | 下降と持ち上げは通過、回転・右の開口が保持基準未達。保持RGB-Dは遮蔽で失敗 |

各フォルダにworld、設計・図面、AI読解と監査、把持候補、RGB-D観測、判定結果、10 Hz軌跡、SHA-256一覧を保存しています。`summary.json` は工程の最終観測を保持します。`capture` は閉指へ進んでいないため、CSVの工具相対滑り欄を空にし、`grasp_reference_available=false` としています。失敗後の `final_open` は試験の後片付けです。

`offline/matched_height` は同じ高さへ下降する32候補の失敗、`offline/raised_support` は支持点を球面上で相対的に100 mm高く残す候補の通過、`offline/rear_fence` は背面ストッパー付きモデルの通過です。各評価で用いたworld・URDF・SHA-256も保存しました。開始関節と把持候補は既存の `../melfa_dual_pick_seed2` の成功記録から取得しています。これは過去の持ち上げ終端を使う経路計画であり、新しい指形状で物理保持できたことを示しません。自己・ケーブル・物体の衝突、接触力、ケーブル支持は未検証です。

再現コマンド・測定値・次の実験は[持ち替え工程](../../regrasp.md)を参照してください。Docker起動復旧後の2試験は左腕だけの接触センサーを使用しています。`single_front/held_pose_check` は失敗した照合の画像・部分検出・深度・ログです。判定用の安定した全3端子の観測は取得できていません。両腕接触監視、照合待ち中も含めた保持判定、照合後の新しい関節観測での計画を追加した最終コードでの物理再試験は未実行です。
