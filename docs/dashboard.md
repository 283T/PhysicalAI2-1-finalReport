# 図面・読解結果・動作を並べる表示

Mac上でローカルモデルを起動し、Docker Desktopを起動する。

```bash
bash scripts/start_local_ai.sh
```

別のターミナルで：

```bash
docker compose --profile gui up -d --build gui
python3 scripts/serve_demo.py
```

[デモ画面](http://127.0.0.1:8080/)を開き、図面AまたはBを選んで「選択した図面を実行」を押す。ローカル推論、指示の検証、Gazebo準備、ピック・挿入・解放の順に進む。

左側に入力図面と実際のAI読解結果、右側にnoVNC経由のGazebo画面を表示する。読解時間、実行中のステップ、解放後の挿入結果を表示する。モデル出力が不正な場合は動作を開始せず、エラーを表示する。

実行ごとに専用GUIコンテナを再起動して新しい基板・部品を用意する。別のターミナルから同じGUIコンテナのデモを重複起動しない。動作中は実行ボタンと図面選択を無効にする。読解結果には図面IDを表示するため、次の図面を選択しても前回の結果と区別できる。

動画撮影時はブラウザ幅を1200 px以上にすると、図面と動作を横に並べられる。初回のモデルロードには追加時間がかかる場合がある。図面AとBの動作を順に撮影し、切り替えの説明を付ける。倍速に編集した場合は動画内または概要欄へ明記する。

## ログと停止

指示は`outputs/dashboard_task.json`、読解監査記録は同名の`.audit.json`、動作ログは`outputs/dashboard.log`、結果は`outputs/insertion_result.json`。表示サーバーはCtrl+Cで停止する。Gazeboを含めて停止するには次を使う。

```bash
docker compose --profile gui stop gui
```

サーバーは127.0.0.1のみで待ち受ける。操作は`http://127.0.0.1:8080/`から行う。POSTは同一オリジンだけ受け付け、公開ネットワークへの提供は想定しない。ポート6080はnoVNC、8080は表示サーバー。
