## 完了条件（変更なし）

ROS 2・Gazebo・ローカルAIで、双腕が柔軟な3分岐ワイヤーハーネスの全コネクタを図面どおりに基板へ物理接続する。図面・基板は整合する。設計・配置を変えて検証し、再実行できるコード、1〜3分動画、PDFレポートを用意する。

実験前に `configs/final_acceptance.json` を固定した。設計seed101・202×配置seed2・7・11×各2回、計12試行で毎回3コネクタすべての接続、開放・退避後2秒以上の安定性、接続済みコネクタの保持を検証する。失敗を保存し、基準を緩めて成功にしない。開発用の単腕把持・運動学・治具試験は最終マトリクスの成功回数に含めない。接触深さを挿入力と扱わず、導通・ラッチは評価対象の幾何接続と区別する。

## 固定条件D101・配置2・P3の比較結果

すべて失敗。治具への着座、持ち替え、基板挿入は未達成。記録は `evaluation/single_nest_20261015`。これらは形状・慣性・実行タイミングを含む単発比較であり、改善率や成功率は示さない。

| 条件 | 通過した工程 | 停止理由 |
|---|---|---|
| 前後ストッパー幅8 mm | 把持・保持・高さ0.35 mへの上昇 | 回転中の相対姿勢差0.05008 rad |
| ハウジング端部ストッパー追加、端部隙間0.3 mm | 画像の位置合わせ | 閉指開口23.69 mm、ピン側パッドとピンの接触を記録 |
| 上記＋ピン側先端を2 mm短縮 | 閉指19.99 mm、保持、上昇、姿勢変更 | 横搬送中の相対姿勢差0.05030 rad |
| 上記＋端部隙間0.1 mm | 閉指20.79 mm、保持 | 上昇中の相対姿勢差0.05232 rad |

端部隙間を狭めるだけでは解決しなかった。ワイヤー支持をもう一方の腕へ移し、荷重を分担してから治具配置・持ち替え・挿入へ進む。これは双腕という元の要件内の実装であり、合格基準の変更ではない。

## 次に実施する工程

1. RGB-Dだけからワイヤー支持点を推定し、連続3フレームで位置2 mm／姿勢0.05 rad以内の安定を確認する。保存画像で3本の候補抽出を実装済み。新規ROS受信でも再起動直後約52.44秒、同じ落ち着いたシーンの再取得約2.65秒で全3本の安定判定を通過。後者は各フレームの候補から安定数を再計算する。記録：`evaluation/wire_support_rgbd_20261016`。単体テスト135件通過。シミュレータ真値は目標生成に使わない。候補は把持・衝突・可到達性の成功証拠とは扱わない。
2. 8 mmワイヤーを挟める支持側の指を用意する。既存の最小開口16 mmでは直接把持できない。開口計測は新しい接触形状に合わせ、空閉じを把持として扱わない。双腕と設備の経路を事前検査し、支持側も接触・滑りを記録する。
3. 固定P3の双腕支持→治具配置→開放・退避→上面持ち替え→基板挿入を物理検証。治具と基板を見られる追加視点、必要なら役割交代を実装する。現在の上面カメラの視野は治具全体を覆わない。
4. 固定条件の全3接続と接続済み端子の保持を統合。
5. 事前固定した12試行を実行し、全試行を保存して検証。
6. 再実行手順・1〜3分動画・PDFを作成して点検。最後に公開・提出の確認。
