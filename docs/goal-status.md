## 完了条件（変更なし）

ROS 2・Gazebo・ローカルAIで、双腕が柔軟な3分岐ワイヤーハーネスの全コネクタを図面どおりに基板へ物理接続する。図面・基板は整合する。設計・配置を変えて検証し、再実行できるコード、1〜3分動画、PDFレポートを用意する。

実験前に `configs/final_acceptance.json` を固定した。設計seed101・202×配置seed2・7・11×各2回、計12試行で毎回3コネクタすべての接続、開放・退避後2秒以上の安定性、接続済みコネクタの保持を検証する。失敗を保存し、基準を緩めて成功にしない。開発用の単腕把持・運動学・治具試験は最終マトリクスの成功回数に含めない。接触深さを挿入力と扱わず、導通・ラッチは評価対象の幾何接続と区別する。

## 次に実施する工程

1. RGB-Dだけからワイヤー支持点を推定し、連続3フレームで位置2 mm／姿勢0.05 rad以内の安定を確認する。保存画像で3本の候補抽出を実装済み。新規ROS受信でも再起動直後約52.44秒、同じ落ち着いたシーンの再取得約2.65秒で全3本の安定判定を通過。後者は各フレームの候補から安定数を再計算する。記録：`evaluation/wire_support_rgbd_20261016`。単体テスト147件通過。シミュレータ真値は目標生成に使わない。候補は把持・衝突・可到達性の成功証拠とは扱わない。
2. 8 mmワイヤーを挟める支持側の指を用意する。既存の最小開口16 mmでは直接把持できないため、左指を各5 mm内側へ延長した最小開口6 mmのモデルを追加済み。開口計測はURDFの接触面と実測関節へ合わせた。直動試験台で8 mmワイヤーの約99.6 mm上昇・保持・開放を2回通過し、摩擦ゼロの保持失敗も正しく検出した。接近・昇降制御の途中4失敗を含め `evaluation/wire_grip_contact_20261016` に保存。これはMELFA・双腕・挿入の成功ではない。双腕と設備の経路を事前検査し、支持側も接触・滑りを記録する。左腕は3枝の候補への6D IKを通過。P3支持経路は右腕が直立なら通過、過去のP3保持姿勢では拒否。拒否工程を特定し、順序・同時上昇・支持点を検討する。単独上昇も検査に含むため、最終把持姿勢が不可能だとはまだ断定しない。
3. MELFA左腕の直接支持を物理検証中。新しい `ArmSession` と `pick_wire.py` は両腕フィードバック、接触センサー配信元30個、固定設備・停止パレットの包絡検査、側面の新規RGB-D再確認を使う。停止パレットが名目位置から0.5 mm／0.002 rad超動いたら停止する。物体真値は保持の独立評価だけに使う。2026-10-16の7試験は全て失敗として `evaluation/melfa_wire_pick_20261016` に保存。
   - 初期のパレットと左ベースの接触を検出。ベースの実包絡寸法に合わせ角の逃げを拡大した。設計・配置seedと最終判定は変更していない。
   - 深度境界の外れ値を支配的な測定平面へ限定して除外。平面残差0.6 mm以下、幅5–11 mm等の既存条件は維持。支持点の希望距離75–200 mmを指定できる。
   - 傾いたワイヤー面に指を合わせると台に接触。指を垂直に保ち、画像から求めた正方形断面の投影幅と実測開口を比較するよう変更。開口差1 mm未満は維持。最終の保持基準も変更していない。
   - 精密IKの終点0.1 mm／0.002 rad、指先を中心の1 mm下へ変更した試験は、側面再確認（中心差1.86 mm）、閉指（実測8.65 mm、予測8.97 mm）、上昇まで実行。ワイヤーの最小上昇95.65 mm、位置関係の最大変化4.52 mm、回転0.414 radで保持を拒否。腕同士・設備の実接触0件。持ち上げただけで保持成功にしない。
   - 回転の主成分は曲げ0.403 rad。接触は隣接2節の端にまたがる。ワイヤー方向の接触長50 mm（各指約40.625 g）を追加し、質量・慣性・包絡箱も更新した。以下の追加比較でも保持は未達成。
   - 追加3試験を `evaluation/wire_contact_length_20261016` に保存。50 mm／左ゲイン3000は位置ずれ8.62 mm・回転0.748 radで失敗。左ゲイン10000はパレット位置超過で停止し保持未判定。パレットゲイン4000／D約126.5にすると記録上の最大変位0.042 mmまで抑えられたが、位置ずれ6.07 mm・回転0.505 radで保持を拒否。指12 N・パレット20 Nの出力上限、0.5 mmの位置監視、保持5 mm／0.05 radは維持。
   - 次は平置きワイヤーの単腕持ち上げを繰り返さず、右腕でコネクタを先に持ち上げてから左腕で6 mm深く把持する協調手順を実装する。単腕の保持成功とは扱わず、最終条件も変更しない。保存RGB-Dでは右腕の既存持ち上げ後、110 mm点の中心高さ177 mm、170 mm点143 mmを観測。新規画像で再確認が必要。
   - 空中ワイヤーの四角断面の別の面からの接近を探索済み。面0／1／3は現行ホバーIK候補では失敗、反対面2は最終接近の腕同士の検査を通るが、直立→ホバーの途中で左手首／指と右前腕が重なる。設備を含む全経路は未通過。次は関節空間の迂回経路または支持腕を先に安全な待機姿勢へ移す順序を計画する。静的包絡箱の判定を緩めない。
4. 固定P3の双腕支持→治具配置→開放・退避→上面持ち替え→基板挿入を物理検証。治具と基板を見られる追加視点、必要なら役割交代を実装する。現在の上面カメラの視野は治具全体を覆わない。
5. 固定条件の全3接続と接続済み端子の保持を統合。
6. 事前固定した12試行を実行し、全試行を保存して検証。
7. 再実行手順・1〜3分動画・PDFを作成して点検。最後に公開・提出の確認。

### 次の協調実装の注意
