# 以前の基礎デモ

## ハーネス接続の最小デモ

- [x] ROS 2 Jazzy＋Gazebo Harmonic、GUI・noVNC、ローカルQwen3-VLを用意する。
- [x] ハーネス端プラグ、短い2本のケーブル、パネル上の受け側J1/J2を配置する。
- [x] 図面A・BにWH1/P1、接続先、原点、mm座標、向きを記載する。
- [x] AI出力をハーネス番号・プラグ番号・接続先・分類・座標・向きへ分ける。
- [x] 誤った番号・座標・向きを動作前に拒否する。
- [x] 図面、読解結果、Gazeboの動作を並べる表示と録画スクリプトを用意する。
- [x] ハーネス版のA・B読解と両接続先への動作を検証し、動画を再収録する。
- [ ] 日本語説明・字幕を整える。
- [ ] PDFレポートを作成する。

## 追加候補

- 異なるハーネスの識別と誤接続の拒否。
- 端末プラグの向きの変更。
- ケーブルの柔軟体または関節付きモデル、接触・張力・絡みの検証。
- 他端が固定されたケーブルの引き回し、ラッチ・導通の確認。

最初はWH1/P1をJ1またはJ2へ接続する1端末のデモを完成させる。固定形状のケーブルを動かす段階と、柔軟なケーブルを扱う段階は区別して評価する。
