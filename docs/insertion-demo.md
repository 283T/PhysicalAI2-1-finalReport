# ハーネス端のプラグ接続

```bash
docker compose run --rm dev python3 scripts/run_insertion.py --task examples/task_a.json
```

`--task`でローカルAIが生成した指示も入力できる。ハーネスWH1・プラグP1・接続先J1/J2・向き0度のみ対応し、不一致の指示は動作前に拒否する。

## 動作

1. 供給台上のハーネス端プラグへ接近する。
2. プラグのハウジングを理想的な固定ジョイントで把持して持ち上げる。
3. 接続パネルの指定ソケット上へ搬送する。
4. ソケットに合わせ、垂直に差し込む。
5. 把持を解放して退避する。
6. プラグの着座位置・姿勢・差し込み深さを確認する。

直交型ロボットのX/Y/Z軸はGazeboのJointPositionControllerで制御する。接続先には高さ40 mmの受け側ハウジングと、2本のピンを受ける空洞を作る。プラグの本体が受け側の上面に着座する。位置を直接書き換える処理はない。

| 項目 | 値 |
|---|---|
| パネル平面原点・接続面高さ | (0.19, 0.10, 0.14) m |
| パネル上面 | Z=0.10 m |
| J1中心 | X=60 / Y=50 mm |
| J2中心 | X=100 / Y=90 mm |
| 着座時のプラグ中心Z | 0.15 m |
| 受け側の高さ・差し込み深さ | 40 mm |
| 受け側の空洞 | 8 mm角×2 |
| ピン | 直径4 mm、長さ40 mm、間隔20 mm |

`board_origin_m`と`configs/board.json`は旧実装との互換性のため名称を維持している。現在のZ原点はパネル上の受け側コネクタの接続面を表す。

## ケーブルと判定の限界

赤・黒の短い2本のケーブルをプラグに付ける。折れた複数の円柱からなる固定形状で、プラグと一緒に動く視覚モデル。ケーブルに衝突形状・曲げ剛性・張力はなく、自由なケーブルの変形や絡みを解いたことにはならない。他端は固定しない。

成功は持ち上げ50 mm以上、解放後の各軸位置誤差1 mm未満、ほぼ垂直の姿勢、差し込み深さ30 mm超、把持解放で判定する。電気的導通、接点圧力、ラッチの係合、実機の摩擦把持は確認していない。接続部を拡大している。

## モデルの変更

配置は`configs/board.json`、生成元は`scripts/build_world.py`。変更後に`python3 scripts/build_world.py`でSDFを再生成する。図面は`docker compose run --rm dev python3 scripts/build_drawings.py`で再生成する。

結果は`outputs/insertion_result.json`と成功した接続先ごとの`outputs/result_J1.json`・`result_J2.json`へ保存する。既定はヘッドレス実行。[GUI表示](gui.md)、[並列表示](dashboard.md)、[録画](recording.md)も利用できる。
