## 各回の開始

1. Gitの状態、進捗、最新の実験終了報告と所有プロセスを確認する。開始時のPIDや古い途中報告だけで稼働を断定しない。
2. 物理試験が稼働中なら二重起動せず、使われている制御ソース・入力を変更しない。
3. 終了済みなら全把持ログ・監視対象接触・動画を再監査し、成功の範囲と未達を分ける。
4. 次の工程を実施し、実行条件・結果・次回の入口をファイルへ保存する。正式評価の試行は実行前に登録する。
