# 最終図面の新規ローカルAI読解（10/29）

D101の図面画像のみをQwen3-VL 2Bへ入力し、出力後に基板情報で照合した。全3行の対応・座標・向きの検査を通過。
画像SHAは正式Bの入力と一致。P3の対象選択は固定仕様であり、AIによる任意作業選択ではない。
この新規推論は提出時の確認で、正式Bは以前に監査した推論を再利用した。正式3試行の入力や判定を変更していない。

最初はローカルサーバー未起動で接続拒否。次は既定のモデル保存先が空でHTTP 404となった。
両方ともモデル回答を受信する前の失敗で、誤答試行とは扱わない。失敗記録とログを保持した。
プロジェクトの `scripts/start_local_ai.sh` で既存 `.cache/ollama` を使い、クラウド無効で起動後に新規読解が通過した。
新たなモデルダウンロードや課金APIは使用していない。
